# Bundled font

`DejaVuSans.ttf` is the unmodified DejaVu Sans font from the official
[DejaVu 2.37 TTF release](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37).
It is embedded in the shared Rust renderer so previews and display buffers use
the same glyphs without depending on fonts installed on the Pi.
