# Daily-quote source

Online quotes are fetched from ZenQuotes; keep attribution and a link to
https://zenquotes.io/ when displaying their free API data.
https://docs.zenquotes.io/zenquotes-documentation/

No third-party quote collection is bundled. The fixture text is an original
Paperphase example. User-supplied quotes stay in local connection settings and
are never uploaded to the provider. Users retain responsibility for their content.
The source's terms are separate from Paperphase's code licence.
